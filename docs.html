NP Annotator

NP Annotator is a browser-based tool for linguists and corpus researchers to tag, gloss, and categorise noun phrases from uploaded datasets. It runs entirely in your browser — no server, no account, no data leaves your computer.

Browser-based No installation CSV & Excel input XLSX / CSV / JSON export Auto-save
Workflow at a glance

Annotation follows a linear five-step process. Once a session is started, you can move freely between the Annotate, Data, Lexicon, and Categories tabs.

Each row in your dataset corresponds to one noun phrase. You work through the list row by row in the Annotate tab. Saved annotations accumulate in the Data tab. Token glosses build your Lexicon. The tag vocabulary is fully managed in the Categories tab.

Uploading a file

NP Annotator accepts CSV, .xlsx, and .xls files. Files are read locally — nothing is uploaded to any server.

📂
Supported formats
FormatExtensionNotes
CSV.csvUTF-8 encoding recommended. Use a comma delimiter.
Excel.xlsxModern Excel format. First sheet is used.
Legacy Excel.xlsOlder format; supported but UTF-8 behaviour may vary.
💡 Don't have data yet? Download one of the sample files on the home screen to explore the tool before using your own dataset.
⚠️ If your file has no header row, uncheck "First row treated as header" after uploading. Columns will be labelled A, B, C… instead.
📥
Importing a saved lexicon

If you have a .json lexicon file exported from a previous session, you can import it in the same upload step. This restores all prior token glosses so you do not have to re-enter them for words that appear again in the new dataset.

Mapping columns

After uploading, you must map six fields before the session can start. All are required. A live preview shows the first rows of your file with column roles highlighted.

FieldColourDescription
Context column purple The full source sentence in which the noun phrase appears. Shown as context during annotation.
Data column blue The noun phrase itself — the text that will be tokenised and tagged.
Data code column amber A per-row identifier from your dataset (e.g. a sentence ID or corpus code).
Language green Language of the dataset. Choose from the list or select "Other…" to type a custom name.
Source name teal Free-text name for the source corpus or document collection (e.g. "BNC Corpus").
Dataset code red Short identifier for this annotation batch (e.g. "EN-01"). Included in all exports.
💡 The live preview highlights each column in its mapped colour. Use it to verify mappings are correct before starting.
Session settings

Once a session is active, a session strip appears in the header showing the current language, dataset code, and column mapping. You can start a new session at any time using the ↺ New session button — this resets the view but your saved annotations in the Data tab are preserved unless you explicitly clear them.

Session settings (language, source name, dataset code) are fixed for the lifetime of a session and are embedded in every saved annotation.

Annotate tab

The main workspace. It has four panels arranged side by side: Rows, Noun phrase, Tag selection, and Gloss.

1
Select a row
Click any row in the Rows panel on the left. The noun phrase and its context sentence load immediately. Rows marked done have already been saved.
2
Edit the noun phrase (optional)
The Noun phrase panel shows an editable text field pre-filled from your data column. Edit it if needed, then click ↺ to re-tokenise. Changes only affect this annotation — your source file is not modified.
3
Select token(s) and apply a tag
Click one or more word chips in the Tag selection panel. Chips turn amber when selected. Then choose a main category, then a sub-tag. The chip turns green and shows the assigned tag below it.
4
Set ordering (multi-token spans)
When two or more tokens share the same tag, an Ordering strip appears. Drag or click to set which token is Head (H), Dependent (D), or Modifier (M).
5
Add glosses
Fill in an English gloss for each token in the Gloss panel. Glosses are required before saving (missing ones turn red). You can also add a phrase-level translation at the bottom of the panel.
6
Save the phrase
Click Save phrase → at the bottom. A validation banner highlights any missing glosses or untagged tokens. On success, the row is marked done and the next row loads automatically.
⚠️ Auto-tag: If a token has been seen and tagged before (via the Lexicon), a suggested tag appears in an amber banner. You can accept it with one click or ignore it and pick manually.
Tag selection

Tags are organised in a two-level hierarchy: main categories and sub-tags. You always pick a main category first, then a sub-tag.

1
Main category

Broad linguistic categories such as Determiner, Noun, or Adjective. Defined in the Categories tab. Click a category button to drill down.

2
Sub-tag

Fine-grained labels within the main category (e.g. DEF, INDEF, POSS). Suggested sub-tags based on prior lexicon entries are highlighted in amber.

S
Sense disambiguation

If a token already exists in the Lexicon with multiple senses (S1, S2…), a sense picker modal opens automatically. Choose the matching sense or create a new one. A small amber dot on the chip indicates the token has a sense assigned.

Gloss panel

The Gloss panel (rightmost column) shows one input per token plus a phrase-level translation field at the bottom. Glosses are English translations of each word form and are stored in the Lexicon for reuse.

A grammatical gloss palette is provided inside each token row. Click any abbreviation chip (e.g. SG, PL, GEN) to append it to the gloss, following Leipzig Glossing Rules conventions.

If a token was glossed in a previous phrase, its prior gloss is pre-filled and a suggestion hint is shown in small text. You can accept or overwrite it.

🚫 Saving is blocked if any token gloss is empty. All gloss fields must be filled in before clicking Save phrase →.
Data tab

The Data tab is a running table of every saved annotation. Each row shows the noun phrase, context, assigned tags, glosses, dataset code, and source name.

Use the export buttons at the top right to download your data. You can also Clear all to wipe saved annotations (a confirmation prompt will appear).

The annotation count is shown above the table and updates in real time as you save phrases.

Lexicon tab

The Lexicon is a cumulative dictionary of every token that has been glossed. It grows automatically as you annotate and can be exported and re-imported across sessions.

Each lexicon entry records: Code (tag assigned), Word form, Language, Gloss (EN), and the number of phrases in which the token has appeared.

A word can have multiple senses (S1, S2…) — for example, the same Turkish suffix can carry different meanings depending on context. Each sense gets its own gloss and tag.

Use the search bar to filter by word form, tag code, or gloss. A warning banner appears if any entry has an empty gloss, because exporting is blocked until all glosses are filled.

↕
Cross-session reuse

Export the Lexicon as JSON, then import it at the start of your next session (Step 1 of setup). All prior glosses will be restored and the auto-tag system will use them immediately.

Categories tab

The Categories tab is where you manage the tag vocabulary used in the Annotate tab. Changes take effect immediately — you do not need to restart the session.

  • Main categories — broad labels (e.g. Determiner). Add new ones with the input at the bottom.
  • Sub-tags — fine-grained codes within each category. Each sub-tag has a short code and a full label.

You can rename or delete any category or sub-tag. Deleting a sub-tag that has already been applied to saved annotations will not retroactively remove those tags from the Data tab.

💡 Click ✎ Edit in the Tag selection header to jump directly to the Categories tab without leaving the Annotate view.
Auto-save

NP Annotator automatically saves your full session state to your browser's local storage whenever you save a phrase. A status bar below the header shows the time of the last auto-save and the total number of saved annotations.

When you return to the page with a saved session, a restore banner appears offering to resume where you left off. Choose Resume session to reload your data, or Start fresh to begin a new session without clearing saved annotations.

To permanently clear all saved data from the browser, click 🗑 Clear saved data in the auto-save bar.

🚫 Auto-save uses browser local storage — clearing your browser data or using private/incognito mode will erase saved sessions. Export your data regularly as a backup.
Exporting data

All export actions are available in the Data and Lexicon tabs. Exports are generated in-browser and downloaded directly — no server involved.

📊
Annotation exports (Data tab)
XLSX
Excel spreadsheet. Best for sharing with collaborators or importing into statistical tools.
CSV
Comma-separated values. Compatible with R, Python (pandas), and most corpus tools.
JSON
Structured data with full tag and gloss detail. Useful for programmatic processing.
📚
Lexicon exports (Lexicon tab)
XLSX
Lexicon as a spreadsheet — useful for manual editing or sharing.
CSV
Flat table of all word forms, codes, and glosses.
JSON ✶
Re-importable format. Use this to carry your lexicon into future sessions.

✶ JSON is the only lexicon format that can be re-imported.

🚫 Lexicon export is blocked if any entry has an empty gloss. Fill in all missing glosses (highlighted in the Lexicon tab) before exporting.
